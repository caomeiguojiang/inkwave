## Compatibility

The fork uses protocol **2** in the browser, Node relay and optional Worker.
Protocol 1 clients are rejected before room creation/join with a refresh message.
Do not mix old and new code in a release. The host still simulates the game;
the server relays messages and maintains ephemeral rooms.

Everyone ready starts immediately. Once the host and a strict majority are ready,
remaining players receive a 30-second grace period. Unready minority clients are
excluded, with identical bot ownership on the remaining clients. A slow host or
majority aborts after the overall deadline. Human-only stage restrictions remain.

Network errors remain stable English identifiers internally and are translated
at the presentation boundary. Player names, room codes and gameplay identifiers
are not translated. The music manifest is generated locally for web packaging;
the repository provides no recordings, so the procedural soundtrack remains.
